How it works

1
Run the exe

No installation. Windows asks for admin rights because Photoshop lives in Program Files.

2
Click Fix Tabs

The app rewrites the tab title templates in Photoshop's localization dictionary. No application code is touched and a backup of every file is kept.

3
Start Photoshop

Tabs show only the file name. Restore brings the defaults back any time. After a Photoshop update simply run Fix again.
